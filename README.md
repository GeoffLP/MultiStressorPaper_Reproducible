# Multistressor analysis of phosphorus boundaries in Greek rivers

This repository provides the processed data, R Markdown analysis notebooks and supporting R functions used to reproduce the analyses, tables and figures for a manuscript examining phosphorus boundaries in two Greek Mediterranean river types: lowland R-M2 and upland R-M4.

The analyses examine ecological status in relation to phosphate and other environmental pressures, select logistic regression models, assess predictive performance and calculate conditional phosphorus boundaries and their uncertainty.

## Repository contents

| Path | Contents |
| --- | --- |
| `Analysis/02_Predictor_Screening.Rmd` | Screening of candidate environmental predictors. |
| `Analysis/03_Model_Selection.Rmd` | Selection and comparison of logistic regression models. |
| `Analysis/04_Model_Evaluation.Rmd` | Model evaluation, spatial cross-validation, probability thresholds, phosphorus boundaries, bootstrap uncertainty, and manuscript outputs. |
| `Data/Processed/Greek_RM2_RM4_SiteMeans.csv` | Processed site-averaged data used by the analyses. |

| `Outputs/Tables/` | Tables and additional numerical results generated by the analyses. |

## Reproducing the analysis

1. Download or clone this repository and open its RStudio project (`.Rproj`) file.
2. Install the R packages required by the notebooks. Package dependencies are declared in the setup sections of the notebooks; the evaluation notebook also uses custom scripts from `Functions/`.
3. Confirm that `Data/Processed/Greek_RM2_RM4_SiteMeans.csv` and the scripts in `Functions/` are present.
4. Open and run the notebooks in numerical order: `02_Predictor_Screening.Rmd`, `03_Model_Selection.Rmd`, then `04_Model_Evaluation.Rmd`. Run each notebook from the beginning, including its setup section.
5. Inspect the generated files under `Outputs/Figures/` and `Outputs/Tables/`.

Paths are relative to the repository root using the R package `here`; no machine-specific drive path should be required. The notebooks can be executed interactively in RStudio.

## Software

The analysis was run using **R 4.3.1** on Windows. Required packages include `dplyr`, `tidyr`, `here`, `ggplot2`, `purrr`, `stringr`, `flextable`, `broom`, `modEvA`, `patchwork`, `mgcv`, `ggnewscale`, `officer` and additional packages called with the `package::function()` syntax. Consult the notebook setup sections for the full requirements. The final section of `04_Model_Evaluation.Rmd` records reproducibility information, including package versions.

## Models and outputs

The selected models include phosphate-only models for both river types and multivariate models incorporating other environmental predictors. The R-M2 multivariate model includes phosphate, conductivity and hydromorphological modification (HMS). The R-M4 optimal model includes phosphate and HMS; an additional R-M4 model includes phosphate, HMS and dissolved oxygen.

`04_Model_Evaluation.Rmd` generates the manuscript tables and figures and supplementary outputs, including spatial cross-validation results, conditional phosphorus boundaries, bootstrap confidence intervals, classification error curves and sensitivity analyses. Its Section 11 lists the exact output filenames.

## Data provenance and scope

The repository supplies **processed, site-averaged observations**, rather than the original individual monitoring records. It is intended to reproduce the analyses presented in the manuscript, not the complete history of exploratory model development or the earlier preparation of raw data.
